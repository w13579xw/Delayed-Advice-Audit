# 相关工作与新颖性审计

检索日期：2026-11-01。本文记录一手论文、项目文档与本项目的研究判断。检索不是穷尽性系统综述，**不保证首创，不保证录用，也不把代码原型当作论文实验结果**。

## 1. 审计结论：一般的“何时调用大模型”已经非常拥挤

“大脑+小脑”“风险高时求助”“预测干预收益”“异步推理”“使用conformal校准”都不能单独作为本项目的新颖性主张。更值得验证的具体问题是：

> 同一条建议从生成到到达之间，环境仍在变化；机器人怎样判断这条已经付费、已经生成的建议在当前状态是否仍值得采纳？同一建议在不同到达时刻的效用是否会改变符号？

建议工作标题：**Should a Robot Obey Advice That Arrives Late? Counterfactual Acceptance of Delayed Interventions**。中文：**迟到的建议还该执行吗？机器人异步干预的反事实采纳与时序有效域**。

可争取的贡献组合是：持续推进环境中的到达时采纳问题、严格配对的时延干预收益曲线、对离散时延网格的有效域估计，以及在视觉控制器上的跨任务/跨时延验证。该组合仍须后续实验与扩展检索确认，不能写成“首次”。

最接近的第一篇必须逐段对照：其§5.10“screening channel”指出，判断状态是否停滞不能判断某次改写是否值得执行；同节“dose axis”说明其按仿真步数计量的实验中，注入延迟不会改变成功率。因此本项目一个可检验的区别是让**任务状态在真实的仿真时间轴上持续演化**。但该文也已有撤销干预与staleness内生性的讨论，不能声称首次发现“求助可能有害”。上表描述限于已读资料，避免把没有观察到的机制当成对方绝对没有。

## 3. 建议的核心对象：Temporal Intervention Validity Envelope

固定一次请求起点i、请求时可见历史h_i、快控制器内部状态，以及由该历史生成的建议z_i。对预先固定的时延网格D，保持**同一条z_i**不变，让基础策略继续执行到各到达时刻d。

在到达状态复制两个完整仿真实例：一个采纳z_i，一个继续基础策略。使用相同、按绝对仿真时间索引的外生扰动轨迹与相同全局结束时间，得到有限时域配对收益：

`G_i(d) = R_i(accept z_i at d) - R_i(continue at d) - switching_cost_i(d)`。

由此定义该建议的时序有效域：`V_i = {d in D: G_i(d) > 0}`。该集合可以为空、全部有效，或由多个不连续时段组成；**不得预设收益随时延单调下降，也不得用一个TTL阈值替代完整假设**。例如某动作早到会打断有效抓取，中间到达可以修正，过晚又会破坏已经完成的放置。是否存在这些现象应由数据检验。

这是真实仿真系统内、指定基础策略/后续执行规则/扰动分布下的收益，不是真实世界的普遍因果效应。单次成对回放测得的是一个实现的收益差；若论文声称条件期望效应，需多扰动重复并报告Monte Carlo误差。建议训练target、校准target与论文符号保持一致。

必须区分两种信息集合：

- **请求前预测**只能使用请求时信息和时延分布，不能读取未来到达画面或未来扰动。
- **到达时采纳**可以使用当前观测、旧观测、建议本身及实测age，不能读取分叉回放结果、未来轨迹或仿真真值标签。

到达时查询费用已支付，应视为沉没成本；采纳比较只计算后续收益和切换代价。请求阶段才扣查询费用。重复扣费会人为制造“拒绝更好”的结果。

## 4. Conformal可以作为工具，不能作为未经证明的新保证

已经存在两类非常相关的统计先例：

1. [Should I Have Expressed a Different Intent?，2026](https://arxiv.org/abs/2601.20090)：对LLM控制中的替代intent做结构因果建模和conformal反事实生成，案例是无线网络控制。它限制了“反事实+LLM+conformal”这一宽泛组合的新颖性。
2. [Conformal Prediction Regions for Time Series Using Linear Complementarity Programming，AAAI 2024](https://ojs.aaai.org/index.php/AAAI/article/view/30089)：用跨时刻误差构造整体预测区域。因此group-max residual同时覆盖是已有统计技术的应用。
3. [Selection by Prediction with Conformal p-values，JMLR 2023](https://jmlr.org/papers/v24/22-1176.html)：选择后错误比例需要专门控制。普通边际覆盖率不能直接解释成“所有被采纳建议中至多alpha有害”。

一个可实现的保守起点是：训练集拟合收益预测f(x,d)与正尺度s(x,d)，独立校准集按完整请求起点分组。每个组包含同一请求的全部预定时延和两条反事实分支。计算单侧非一致性分数：

`r_i = max_{d in D} [(f(x_i(d), d) - G_i(d)) / s(x_i(d), d)]`。

在n个独立校准组上取`k = ceil((n+1)*(1-alpha))`对应顺序统计量q；若k>n应使用正无穷边界，而不是把k截到n。下界为`L_i(d)=f(x_i(d),d)-q*s(x_i(d),d)`，预测有效集合为`{d: L_i(d)>0}`。

在预测器固定、组间可交换、校准组与新组同分布、同一预设有限网格的条件下，这支持**新请求组在所有网格时延上的同时下界覆盖**。它不是每个状态的条件覆盖，不覆盖任意连续时延，也不保证任意分布外时延/任务；需要插值时应明确额外光滑性假设或仅做经验评测。

数据切分必须以**完整episode/场景家族**为最低单位，禁止把同一快照的不同delay、分支或相邻帧分到train与calibration/test两侧。如果同一episode包含多个强相关请求，可把整episode视为一个组并对预先规定的请求×时延集合取max；不能把它们冒充独立校准样本。

更关键的是：部署gate会改变后续状态分布，因此离线固定行为分布上的覆盖**不能自动传递到自适应闭环**。离线覆盖、闭环经验有害采纳率和任务成功率应分别报告。对闭环重复决策的形式保证，需要额外的策略条件校准、在线有效方法或明确的整体trajectory构造；当前原型不得宣称已经解决。

## 5. 单3090、无真机时的实验层级

### 诊断层：便宜但不能独立支撑机器人顶会结论

Toy与FetchReach可验证事件时钟、快照恢复、同扰动配对、训练/校准分组和接受逻辑。解析快策略与解析专家只用于隔离机制。若所有结果停留在这个层级，论文应称状态控制诊断研究，不能称已验证通用VLA/Robotic Agent。

### 投稿层：至少两类控制器与视觉任务

- 选一个有已发布成功checkpoint的视觉操作基准，先验证原始成功率，然后冻结策略。主方法只训练小型收益预测头，不进行7B级全参数训练。
- 至少两类基础控制器或两个不同模型家族，以避免gate只是对一个策略错误模式拟合。
- 在视觉操作任务中加入可解释扰动：目标移动、物体被推开、暂时遮挡、运动速度改变。正常无扰动任务必须保留，避免设计一个只奖励拒绝的人工环境。
- 慢专家使用本地小型VLM或冻结策略规划器，保存请求、响应、模型版本与实际延迟轨迹。缓存回放可用于公平重放；但要区分测量延迟与合成注入延迟。
- 在另一仿真任务家族上做迁移验证。资源不足时，优先保证小而完整的跨任务实验，而不是大量只有一两个seed的任务。

LeRobot官方异步文档给出的参考推理占用是π0约14GB、SmolVLA约2GB；这只是模型推理参考，并非本项目端到端显存承诺。[官方文档](https://huggingface.co/docs/lerobot/async)。单3090可采取分阶段采集、缓存视觉特征、训练小头、顺序加载不同模型。具体每小时轨迹数和总工期必须先profiling再估算。

## 6. 必须设置的对照与失败条件

至少包含：fast-only；固定周期请求+全部采纳；固定周期请求+age阈值丢弃；风险/进度触发；仅当前状态价值gate；加入age但不做配对标签的gate；请求+到达双门控；无conformal的收益gate；group-conformal有效域gate；oracle到达采纳上界。若复现论文机制有限，应标“inspired baseline”而不是声称完整复现RTC/JITI/TIC-VLA。

请求策略和采纳策略分开实验：首先固定同一请求时间表与同一专家响应，隔离采纳增益；再比较闭环联合调度。主比较匹配实际调用次数或费用，不能让某一方法偷偷使用更多专家。

关键结果应同时包括：原始成功率、连续回报、碰撞/约束违反、完成时间、每episode调用与拒绝数、有害采纳率、正收益建议漏采纳率、校准覆盖和区间宽度。Bootstrap或置信区间按episode/初始场景聚类，报告配对差异；主要比较与多重比较校正应预先确定。

以下任一情况出现，应缩小论文主张或停止扩大实验：

- 无延迟专家也无法改善基础策略，说明帮助渠道无能力上限；
- 同一建议的收益与age无明显交互，简单阈值已达到同等收益；
- 学习gate只能在解析专家或状态输入上有效，视觉策略迁移失败；
- 遮掉未来信息后收益消失，说明特征或数据切分泄漏；
- 校准下界过宽导致几乎全部拒绝，应报告保守性与效用损失，而非只宣传覆盖率；
- 不同方法的随机扰动、终止条件、动作预算或实测时钟不一致。

## 7. 适合怎样的投稿叙事

在缺少真机的条件下，较可信的目标是方法与评测充分的CoRL/ICLR/NeurIPS方向：清楚定义延迟建议的收益对象，以严格模拟实验和跨控制器证据支撑。T-RO/IJRR等期刊通常需要更完整的理论、系统和广泛验证；当前原型与研究计划并不足以支持“能发顶刊”的判断。选题应先通过机制诊断与强基线检查，再根据实验事实决定投稿定位。

本项目最有希望的主张不是“机器人知道何时思考”，而是：**机器人在执行过程中，能够对一条迟到建议重新评估其效用，并在可验证的条件下避免采纳已经不适用的干预。**这仍是待检验的研究假设。

## 补充：必须纳入的两篇最近邻

- [RESCUE (2026-10-09)](https://arxiv.org/abs/2610.13516)：已恢复仿真和策略状态，通过反事实分支分析报警是否值得响应及最晚可恢复检查点。不能把分叉标签或恢复期限本身作为新意。
- [ForkCast (2026-10-13)](https://arxiv.org/abs/2610.18650)：对Commit/Reobserve/Replan预测反事实未来并选择动作。因此“候选增益排序”也已存在。本项目能否立足，取决于冻结一条请求时建议、改变其实际到达时间后产生的效应，及在连续运行视觉系统中的证据。

这两篇的重叠风险已在研究计划中作为首两周的go/no-go条件。
