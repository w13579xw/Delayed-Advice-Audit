# Zenodo archive

Title: **Delayed Advice Audit: Code and Analyzed Data**.

DOI: `10.5281/zenodo.24050071`.

Current status: DOI reserved; files uploaded to a private draft; public registration awaits author confirmation of release licensing. A reserved DOI does not yet resolve to a public downloadable record. The article availability statement uses future tense until publication.

The draft contains original software and native experiment/analysis drivers, the compact manuscript/supplement analyzed-data package, and a small NumPy offline audit. The latter reproduces eight fitting/selection cells, 500 runtime choices and six primary paired-result vectors from cached normalized kernel distances and development labels. It does not independently verify feature extraction or kernel-distance construction and does not rerun native simulation. Third-party demonstrations, pretrained neural-network weights and the complete native trajectory archive are not redistributed.

Proposed release terms: MIT for original code; CC BY 4.0 for analyzed data; third-party components retain their original notices. These terms have not yet been confirmed by the authors. No license change to the repository is implied by preparing the draft.

Release files are prepared locally in `archives/zenodo_v1.0.0/`; these new ZIP files are not tracked in Git. The compact numerical source data already distributed in `archives/` remain unchanged. Internal preparation and verification records are in `outputs/zenodo/20261108/`.
