# 修复、专家来源与可学习性：新增实验结果

日期：2026-11-02。实际运行结果；不是以oracle冒充模型。原始协议、数据、失败与旧结果均保留。

## 全部实验支持的观点

**当前手写reach通道中，建议的可恢复收益、专家内容的增量价值与模型能实现的收益是三件不同的事。已有gate和新增选择器都没有稳定超过强本地对照。**

已有截止/成本审计显示候选收益小；检查点/时钟五种子研究没有一致时钟效用优势，coverage对齐效应因后端而异。当前不能推出所有异步专家/VLA无效、任何收益回归都学不会、或者conformal理论失效。两个后端仍是同类reach包装任务，非独立操纵机制。

## 增加了什么研究内容

新问题：**修复迟到建议后获得的收益，究竟依赖专家内容，还是廉价本地控制也能获得？** 新增同请求、同未来、同修复族的来源替换对照；它针对“修复奏效就代表专家有效”的归因漏洞。工程实现不等于文献首创，全球新颖性仍待全文对照及外部验证。

- 3来源：原手写专家、原local(P6)的名义展开、较强P12廉价名义展开；local本身保持P6。

- 5操作：reject/raw/prefix3/suffix/反馈track。都是简单既有控制思路，不宣称复现完整RTC/FutureRTC。

- 真实学习原型：每模型seed12个选项回归head，观察量输入；5seed。full/cheap-only分别校准，不能故意给cheap-only更宽的界。

- 新增后处理：portfolio正部增量与精确regret账目；另做固定到达状态、多未来跨拟合诊断。标准代数和Monte Carlo不称新理论。

## 第三阶段：来源归因及选择误差（明确事后描述）

在同一新test池，E=max专家修复收益，C=max两种廉价源修复收益，均包含reject=0，A=max(E,C)。新增专家的portfolio机会是I=E[A−C]，非负，允许专家仅在部分状态胜出。它比有符号E[E−C]更适合描述“向cheap选项集再加专家”的上界增量。

|量：均值 [95% CI]|Toy|Fetch|
|---|---|---|
|expert_oracle|0.000277736131 [0.000260495053, 0.000297917881]|0.000309840649 [0.000262114336, 0.000359593302]|
|cheap_oracle|2.76670407e-05 [1.91947886e-05, 3.67675835e-05]|0.000445790334 [0.000380611495, 0.000514468638]|
|portfolio_increment|0.000250332826 [0.000231901646, 0.000269079357]|2.06146921e-06 [2.07546922e-07, 4.45488232e-06]|

Fetch cheap oracle / all oracle = **99.54%**；专家额外机会仅约2.06e-6。在此声明的控制/修复族内，原本看似专家专属的价值大部分可由廉价组合替代；不代表任意专家无信息。Toy仍有2.50e-4增量机会，说明不能简单把两个后端归为同一失败机制。

固定学习器的逐行精确账目：

```text
G_full − G_cheap = (A − C) − (A − G_full) + (C − G_cheap)
学习收益差          专家机会      full选择regret       cheap选择regret
```

两backend五seed逐候选等式最大绝对误差均0；这是标准代数，不是新定理。

|full_regret|0.00529886057|0.00248936446|
|cheap_regret|0.0034919546|0.00201886706|
|learned_difference|-0.00155657315|-0.000468435925|

Toy full regret约0.00530，远大于2.50e-4专家机会；Fetch机会仅2.06e-6，增加选项后的相对选择误差约4.70e-4。不能用这些数证明所有可能学习器的下界；它们解释的是当前冻结原型。

## 可争取的论文贡献与尚缺证据

1. **测量协议贡献候选**：同候选、同原截止、同扰动，把原样执行、修复与专家来源替换分开，明确费用/支持范围/选择误差。

2. **归因发现**：新Fetch候选池中强廉价组合几乎解释全部修复oracle；Toy仍有机会却未被当前学习器获取。一个统一的“门控失效”表象下，来源不足与估计不足应分开检验。

3. **可复现实证包**：冻结四池、五seed、配对方案、完整负结果、来源/代码hash、可重放截止失败案例。工程完整性是证据基础，不独立构成算法创新。

这些足以支持一份诚实的技术报告/测量论文草稿；**尚不足以声称有竞争力的方法论文已经成立**。时间反事实、反馈修复、执行块选择、回归ensemble与conformal均已有相关研究；见SCIENTIFIC_POSITION_AND_NEW_DIRECTION.md的一手近邻链接。新增问题是否足够新颖，仍需全文逐项比较。

优先后续路线：独立且本身有能力的建议源、至少一个非reach操纵机制；先验证local与建议源干净能力，再在全新测试池检验同修复族来源增量及真实闭环收益。停止在当前test上增加网络/阈值搜索。视觉模型与真实服务时延若不实际接入，就不写入论文主张。

## 第四阶段：固定到达状态、重采样未揭示未来（探索pilot）

### 当前结论与下一阶段决策

新增实验增强了“修复机会、专家来源增量、可实现选择收益需要分开”的解释；否定了当前原型已有效的主张。未来未知作为主要失败解释仍未得到支持。现在转回独立建议源与任务机制设计，不继续在已看的test上训练新变体找显著值；外部效度未完成，论文不标为可投稿完成。
