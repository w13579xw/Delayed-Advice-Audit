# Delayed Advice Audit — Source Data

Article: **Auditing the Value of Delayed Advice in Autonomous Agents**.

This compact archive contains 22 analyzed source records: 19 JSON and 3 NPZ files. It supports the reported visual/state comparisons, training replication, message-channel experiments and decoder control. It does not include the full demonstrations, trained model weights or all native trajectories.

`manifest.json` records current release SHA-256 hashes and separate frozen-original hashes. Project labels and display paths were normalized for this release; every numerical field is unchanged and the NPZ files are byte-identical. Historical hashes refer to the original byte sequence, not the normalized release copy. Original records remain in a private provenance backup.

No public data archive, DOI, license clearance or journal upload is asserted. Before submission, authors must approve data/model permissions and deposit the appropriate material under the same project and article names.
