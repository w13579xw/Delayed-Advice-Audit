# Delayed Advice Audit — Source Data

Article: **Auditing the Value of Delayed Advice in Autonomous Agents**.

This resource contains 19 analyzed JSON records, 3 NPZ arrays and the corresponding table fragments. Quantitative values and numerical arrays are unchanged. Machine-specific locations and opaque implementation identifiers are omitted. It is a compact evidence resource, not a complete distribution of demonstrations, model weights and native trajectories.
