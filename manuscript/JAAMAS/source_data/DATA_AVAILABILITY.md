# Delayed Advice Audit — Source Data

Article: **Auditing the Value of Delayed Advice in Autonomous Agents**.

This resource contains 20 analyzed JSON records, 3 NPZ arrays and the corresponding table fragments. Quantitative values and numerical arrays are unchanged. Machine-specific locations and opaque implementation identifiers are omitted. It is a compact evidence resource, not a complete distribution of demonstrations, model weights and native trajectories. The code and analyzed data are associated with the Zenodo record https://doi.org/10.5281/zenodo.24050071. The authors are Junxiang Wang and Jiaoyang Su. Archive DOI: 10.5281/zenodo.24050071 (reserved; record not yet published).
