# Delayed Advice Audit — Submission Materials

Article: **Auditing the Value of Delayed Advice in Autonomous Agents**.

This bundle contains the manuscript, Online Resource 1, Information Sheet and cover letter drafts, editable LaTeX sources, graphics, Springer class assets and compact analyzed source data. Run `bash build.sh` with a standard pdflatex installation to compile the four documents. Machine-specific locations, project-hosting addresses and opaque implementation identifiers are omitted. Internal engineering audit records are maintained separately by the authors.

Author identities, approvals, permissions, licensing and access arrangements remain to be confirmed. No journal submission or public archival deposit is implied.
