# Delayed Advice Audit — Submission Materials

Article: **Auditing the Value of Delayed Advice in Autonomous Agents**.

This bundle contains the manuscript, Online Resource 1, Information Sheet, Title Page and cover letter, editable LaTeX sources, graphics, Springer class assets and compact analyzed source data. Run `bash build.sh` with a standard pdflatex installation to compile the five documents. Machine-specific locations, project-hosting addresses and opaque implementation identifiers are omitted. Internal engineering audit records are maintained separately by the authors.

Authors are Junxiang Wang and Jiaoyang Su, with Jiaoyang Su as corresponding author. Both authors have confirmed their review and submission approval. No funding was received and no competing interests are declared. Code and analyzed-data archive DOI: https://doi.org/10.5281/zenodo.24050071 (reserved; record not yet published). No journal submission or public archival deposit is implied.
