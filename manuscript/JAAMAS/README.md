# Delayed Advice Audit

Article: **Auditing the Value of Delayed Advice in Autonomous Agents**.

Current files:
- `Delayed_Advice_Audit_manuscript.pdf`: main article.
- `supplement/Delayed_Advice_Audit_Online_Resource_1.pdf`: Online Resource 1, supplementary material for the same article.
- `submission/Delayed_Advice_Audit_Information_Sheet.pdf`: Information Sheet for the same article.
- `submission/Delayed_Advice_Audit_Cover_Letter.pdf`: initial cover letter draft for the same article.
- `source_data/`: compact analyzed source records, current and frozen-original hashes, and availability statement.
- `figures/`: graphics and current release metadata, all associated with the same project and article.

Run `bash build.sh` to compile all four PDFs. A standard pdflatex installation and supplied Springer assets are required; the original workspace also has an unprivileged TeX fallback. `RELEASE_PROVENANCE.md` distinguishes normalized release copies from frozen experiment records. The repository export in `manuscript/JAAMAS/` is copied from the canonical Springer authoring project.

The study separates pipeline performance, runtime message dependence and predefined channel value. It does not establish generally beneficial advice use. Author identity, approvals, funding/conflicts, overlap and data/model permissions still need author verification. No public archive DOI or journal submission is claimed.
